 Лабораторная работа №1: Сортировка пузырьком

## Описание задачи

Реализована программа на Python (3.12.9), которая выполняет сортировку массива пузырьком по возрастанию и подсчитывает количество выполненных перестановок

**Входные данные** (Консольный ввод)
1) количество элементов массива n (1 ≤ n ≤ 1000);
2)сам массив из n целых чисел, разделённых пробелами

**Выходные данные**:
1) отсортированный массив;
2) количество перестановок, выполненных алгоритмом

## Требования, реализованные в программе

1) Сортировка пузырьком с подсчётом обменов
2) Обработка некорректного ввода (не числовые значения, неверное количество элементов, числа вне диапазона [–10^9, 10^9], повторяющиеся элементы)
3) Автоматическое тестирование из файла tests.txt

## Структура проекта

1) main.py — основной файл с программой и автоматическим тестированием
2) tests.txt — текстовый файл с 10 тестовыми случаями (следующий формат записи (строк): n, массив, ожидаемое количество перестановок – каждая тройка строк соответствует одному тесту)
3) README.md — этот файл
